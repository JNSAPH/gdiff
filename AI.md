# AI use in gdiff

Code in gdiff is written by a human with help from agentic coding tools. A human with real, professional coding experience oversees these tools. Architecture, design, ideas, and UI/UX are decided entirely by a human. Some architectural and design decisions are discussed with AI, but agents do NOT implement entire features on their own.

## Code review

All AI-written code is reviewed by a human developer with real professional experience.

## Documentation

Documentation may be entirely AI-generated or contain large amounts of AI-generated text. A human with knowledge and experience in this codebase proofreads and validates it.

## This document

A human wrote this document. AI checked the grammar and corrected it. No text was generated by AI — only corrected and proofread.
